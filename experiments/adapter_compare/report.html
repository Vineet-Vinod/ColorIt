HAVC equivalence

HAVC_cmnet2dit uses the same DINOv3 CMNET2 checkpoint family. Its default path uses a sliding bank of 20 references, roughly 512×288 processing, and continuous temporal state. Our successful path uses all 87 curated references, 683×384 processing, and resets at detected scene boundaries. Those differences can affect costume consistency even with identical reference images. Native versus Hugging Face DINOv3 arithmetic was not compared.

MLX optimization

The port uses Metal attention and matrix operations, with compiled normalization and residual fusion. A random-weight block at 16,320 video tokens took 788 ms MLX / 798 ms MPS, about 1% faster. The small-window 27% advantage did not hold at movie scale. This excludes transfers and other pipeline work; trained-weight parity is still pending. Local CI passed 11 experiment tests and 38 project tests, plus types and lint.

Frames and test conditions

FCTCVC uses the released 16.78M-parameter checkpoint, about 67 MB of FP32 model weights. Its 15-frame windows receive aligned colored first and last frames. This tests propagation with excellent, dense anchors, not automatic palette choice. The initial 25-frame check washed out color; the released 15-frame setting performed better. Three previously missed source cuts were visually verified and added before the final run.

LTX setup selects the official convolutional VAE for Mac compatibility, source-video conditioning and palette text, strength 1 and seed 42. The prepared stage-1 runner uses 121-frame chunks with 17-frame carry. End-to-end execution remains unverified.
